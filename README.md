# YupItzAfi Dxmt

## How do I install these formulae?

`brew install yupitzafi/dxmt/<formula>`

Or `brew tap yupitzafi/dxmt` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "yupitzafi/dxmt"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
